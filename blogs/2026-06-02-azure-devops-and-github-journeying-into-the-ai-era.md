Microsoft is positioning GitHub as the primary platform for AI-powered development workflows, announcing Enterprise Live Migrations (Preview) that enable organizations to move multiple repositories from Azure DevOps to GitHub with minimal downtime while preserving history and metadata. Microsoft itself has migrated 1,575 repositories to GitHub with over 3,000 developers now using the platform, and 45% of pull requests occurring there. Azure DevOps users staying on the platform gain Copilot Code Review, Autofix for CodeQL security alerts, Apple Silicon Mac support for Pipelines, and a new Azure DevOps remote MCP server for AI agent integration.
