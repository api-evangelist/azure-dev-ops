Microsoft is migrating its internal repositories from Azure DevOps to GitHub to gain access to AI-native development capabilities, with the Copilot, Agents, and Platforms organization having already moved over 1,600 repositories and 3,100 developers over the past six months while maintaining a hybrid model that preserves Azure Boards and Pipelines workflows. The migration is driven by GitHub's advanced AI features like Copilot Coding Agent and agentic workflows, which enable automated repository scanning and remediation. The post acknowledges significant user pushback about managing two platforms simultaneously, noting that Azure DevOps continues to offer strengths in portfolio management, advanced planning, test management, and release governance.
